# 验证记录

日期：2026-11-09。测试机器：Windows build 26300.9711（26H2），x64，两个 2560×1440 显示器，100% 缩放。Electron 44.9.1，Node.js 24。未把此环境的通过结果等同于所有 Windows 10/11 版本通过。

## 已通过

- TypeScript 严格类型检查、electron-vite 生产构建。
- Vitest 9 项：无输入不计时、键盘长按与鼠标按钮去重、五分钟边界、每连续小时提醒与三十分钟到期、关闭提醒保留连续计时、停止后无尾部补算、跨午夜分摊、当日汇总恢复、系统时间跳变不影响单调时长、104 个唯一键位（部分场景合在同一个测试中）。
- 真实 Electron 源码运行及打包后运行：桌面挂载无错误、utility process 全局输入就绪、主屏居中且无负坐标偏移、截图布局检查。
- 原生系统 Shift 按下/抬起：键帽和猫爪动作出现，统计只增加一次；测试后释放按键。
- 设置窗口、面积调整、切换到副屏并返回主屏、点击指令触发六秒台词。
- 销毁桌面窗口后自动重建：模拟 Shell 销毁子窗口，不重启用户的 Explorer。
- 两张 imagegen 素材均含真实 alpha 通道，输出图和设置截图经过视觉检查。
- NSIS 当前用户安装包构建成功；生产依赖和完整依赖审计均为零漏洞。
