# 懵薯

Windows 桌面上的写实小猫，陪你敲键盘，也记得提醒你休息。

## 使用

完整解压 `release/懵薯-1.0.10-Windows-x64.zip` 到固定文件夹，双击其中的 `懵薯.exe` 即可运行，无需安装 Node.js、Python 或其他运行环境。保留同目录的配套文件，不要只复制一个 exe。开机自启使用解压后的程序位置。

应用在右下角通知区域显示懵薯托盘图标，右键打开菜单，提供“开机自启”开关、“调试”子菜单和“退出”。“调试”里可以按顺序预览面板造型（“面板特效”）、模拟工作满 1 小时（同时弹出休息提醒和休息造型），以及让面板恢复正常。休息提醒可点击“我知道了”关闭，或在 30 分钟后自动消失。再次运行程序会重新连接桌面，不会打开独立设置窗口。

猫、键盘、面板和气泡都在桌面图标下面，普通窗口会遮住它们。默认整体场景在主屏工作区水平、垂直居中，占工作区面积约 5/8。小屏幕保持比例优先，面积可能受屏幕边界限制。

软件启动、桌面首次加载完成后，猫固定说“酥饼好喵！我素薯薯养的键盘猫~”，显示 10 秒后自动关闭，期间点击猫不会替换或延长欢迎语；桌面窗口恢复时不会重复欢迎语。

点击猫随机出现 520 条短台词中的一条，每次成功弹出新台词话框时独立有 22% 概率从混合音效池播放一声，台词在 3 秒后自动关闭；话框消失前的点击不会更换台词、重新计时或触发猫叫，消失后再次点击才会出现新台词。连续工作每满一小时从 1314 条休息文案中随机选一条显示，气泡下方的“我知道了”可关闭提醒，未确认则在 30 分钟后消失。每次提醒期间文案保持不变，连续两次提醒不重复。无操作的五分钟内仍算工作，满五分钟后连续计时清零。锁屏、睡眠、暂停立即停止连续计时；重新启动保留今日汇总，但不恢复连续工作段。长按一个键仅计一次，滚轮和移动仅更新活跃时间。支持标准 104 键及数字键盘关闭 NumLock 后的映射。

统计面板嵌在数字键区上方的键盘空白处，透视与键盘保持一致，显示“敲薯”次数（键盘敲击次数）和今日工作时长，时长采用“x 时 x 分”格式。连续工作每满 20 分钟，面板换上一种特殊造型，10 分钟后回到正常显示；满 1 小时（以及之后每个整点）改为显示提醒休息的造型，点“我知道了”或 10 分钟后恢复。常规造型与休息造型各 30 种，每类 25 种动态、5 种静态，连续两次不重复；动态造型只用 CSS 动画，系统开启“减少动态效果”时定格为静态。中途离开超过 5 分钟，连续计时清零，20 分钟周期也重新开始。面板按键盘图片的相对位置定位，边缘收进外壳；桌面不再显示齿轮，设置入口移至右下角托盘。猫爪仅随键盘敲击动作，界面不再显示鼠标或鼠标次数。

猫和猫爪在静止时保持轻微摆动，打字越快摆动节奏越快。猫上下摆动范围为 4px，猫爪上下摆动范围为 2.8px，同时伴随轻微平移和旋转。

明显快速乱按时，懵薯会叫一声，并随机吐槽：“敲慢一点，我要晕薯了~”“爪子要打结啦，再敲这么快真的要薯了~”“键盘快冒烟啦，给懵薯留口喘气的时间嘛~”。判断条件为 1.5 秒内至少 24 次新按下、至少 6 个不同按键、持续至少 0.7 秒；修饰键和长按自动重复不计入。气泡显示 4.5 秒，两次反应至少间隔 3 秒，持续乱按不会一直叫，需要先停顿至少 1.2 秒再重新触发。暂停、锁屏、睡眠会清除检测窗口。音效从内置的 30 声猫叫、1 声狗叫和 9 声其他动物/怪叫中随机播放，无需联网；隐藏时不叫。

猫叫素材来自 Freesound（28 条公开 HQ MP3）与 BigSoundBank（2 条 MP3），逐条核对 CC0 授权。其中 9 条音效来自 BigSoundBank，另有 1 条老鼠叫来自 Directory.audio，分别为 1 声狗叫，以及鸭、公鸡、牛、羊、驴、猪叫模仿、鸟叫和人模仿猫叫各一声；另加入老鼠叫一声。每轮随机打乱全部 40 条，播完再洗牌，避免连续重复；保留原始音高；新增音效剪到 2.8 秒以内并淡入淡出，播放时调整音量并限制峰值，不叠加播放。来源、作者、下载链接与 SHA-256 记录在 `src/renderer/assets/meows/sources.json` 和 `src/renderer/assets/animals/sources.json`；分发包附带 `猫叫素材来源.txt`。制作阶段可运行 `python scripts/fetch-meows.py` 获取素材（需要 requests）；新增音效制作脚本为 `python scripts/fetch-animal-surprises.py`（需要 requests 和 FFmpeg）；运行应用不联网。

任何时刻只显示一个话框。每小时休息提醒优先级最高：出现时清除已有普通台词，显示期间的欢迎语、摸猫和快速敲击台词均不插入、不排队，关闭后不会补播旧话框。

每小时休息提醒弹出时保持安静，点击“我知道了”关闭提醒后叫一声。提醒持续显示、自动到期和重复确认不会叫。

部分摸猫和休息文案加入懵薯的谐音口吻，如“好薯！”“薯的”“素的”“蛋树”“薯适区”；懵薯是“薯薯”养的猫，薯薯也是这个软件的开发者；软件使用者是薯薯的朋友，懵薯称呼使用者为“二狗”“薯饼”或“酥饼”（同一个人的三个小名），这些称呼散布在摸猫、休息和键帽飘字文案中，少数台词会提到薯薯。

数据保存在 `%APPDATA%/Mengshu/state.json`，诊断信息位于同目录 `diagnostics.log`，不保存按键序列或输入文本。每五秒保存，意外退出最多丢失约五秒数据。未启动期间不统计。素材生成后应用完全离线运行。

## 开发与构建

需要 Windows x64、Node.js 24 和 npm。执行：

也可以直接双击项目根目录的 `start.cmd`：首次启动会在缺少依赖时自动安装，然后直接显示桌面开发版，无需打包。保持命令行窗口打开，保存界面代码后热更新，修改主进程代码后自动重启，修改 preload 后自动刷新界面；按 Ctrl+C 停止。开发数据单独保存在 `%APPDATA%/Mengshu-dev/`，可与正式版分别启动。

```powershell
npm ci
node node_modules/electron/install.js
npm run dev
```

```powershell
npm test
npm run build
npm run test:smoke
npm run dist
```

原生依赖使用 N-API 预编译包，打包关闭重复编译。`electronDist` 指向本地已安装且校验过的 Electron 分发目录，避免打包阶段重新下载。默认只生成 Windows x64 ZIP 便携包，不再生成 Setup 安装程序。代码签名未配置。

`release/` 只保留当前一个版本：`win-unpacked/` 程序目录、一个 ZIP 和 `SHA256SUMS.txt`。仅在需要交付时运行 `npm run dist`；日常修改运行开发或构建命令即可。重新打包前脚本检查是否有 release 中的程序正在运行，通过后清理旧产物，再写入当前版本，不累积历史便携包。

## 结构

- `src/main`：桌面 Win32 适配、输入 utility process、工作计时、存储与面板菜单。
- `src/preload`：类型化隔离桥接；渲染端不启用 Node。
- `src/renderer`：104 键布局、猫爪动画、统计、气泡和齿轮菜单。
- `tests`：可控时钟单测和真实 Electron 冒烟测试。冒烟使用独立数据目录，不注册自启。
- `docs/face-comparison.html`：原图与生成主体对照；面部相似度须人工验收。
- `docs/assets.md`：素材来源及原始生成提示词。
- `docs/TESTING.md`：已验证项目与未覆盖项目。

Windows 的 WorkerW 桌面层属于 Shell 实现细节；桌面结构变化时程序自动尝试重连，也可以再次运行程序触发重连。异常记录在诊断文件中。首版仅交付 Windows x64；未加入账户、云同步、联网聊天或自动更新。

## 1.0.1 视觉调整

猫主体直接由原照片抠出，只修改 alpha，裁切区域 RGB 已逐像素校验一致。键盘改用内置 imagegen 制作的 PNG，代码仅保留透明的按键高亮与落点映射。前爪缩短、加宽；鼠标移动与滚轮不触发爪子动作，鼠标点击仍会触发。统计只保留四项，删除英文标题、日期、标语和说明小字。

## 1.0.2 调整

猫的 alpha 轮廓增加平滑与向内羽化，脸部原始 RGB 依然保持不变。移除托盘和独立设置窗口，保留桌面置底窗口并跳过任务栏；齿轮菜单只有开机自启和退出。旧版本的隐藏/暂停状态不会在启动时将应用置于不可操作状态，自启偏好和今日数据继续保留。

## 1.0.3 手工修边与便携分发

轮廓以 `scripts/cat-outline.json` 中的 118 个手工锚点为准，逐段核对耳缘、头顶、两侧脸颊、颈肩和躯干。运行 `python scripts/refine-cat-manual.py` 可从原照片重建 alpha（仅制作素材时需要 Pillow、NumPy、opencv-python）。RGB 完全来自原图；`docs/edge-review` 保存放大描线及深浅背景复查图。

`npm run dist` 只构建 ZIP，包内仅包含运行所需文件（中文语言包），解压即用。历史版本的 Setup 文件不属于当前分发。

## 1.0.4 毛尖细节

保留手工轮廓作为实心主体，在手工选择的头顶、耳缘与两侧脸颊边界带中，用原照片的颜色信息还原细毛 alpha；不再以一条连续平滑曲线裁切头顶。抑制粉色笼子背景并去除悬浮 alpha 碎片，全部 RGB 及面部内区保持不变。

当前素材复现入口：`python scripts/extract-cat.py`，制作素材时另需 `pymatting`。此步骤只在开发制作素材时运行，便携版无需 Python。头顶前后对照见 `docs/edge-review/head-fur-comparison-dark.png`（上旧下新）。

## 1.0.5 卡通鼠标

鼠标外观改为与键盘配套的内置 imagegen 透明素材。左、右、中键点击分别显示反馈并驱动右爪；移动和滚轮仍不驱动猫爪。

## 1.0.6 毛边效果与无标志鼠标

按最新要求在轮廓下方补入 imagegen 细毛笔刷效果，使用附近原图毛色匹配，细小硬边只向内柔化。五官和主体内区保留原照片像素；外侧毛丝属于新增效果，不再声称整张 PNG 的每个 RGB 都等于原照片。复现仍运行 `python scripts/extract-cat.py`。

鼠标掌托爪印已通过 imagegen 局部编辑移除，鼠标外观仍使用图片。便携 ZIP 解压即用；更新时先通过齿轮退出旧版。

## 1.0.7 照片猫爪

左右爪分别使用新照片中上方与下方的真实前爪，手描轮廓后细化 alpha，去除人手和地面。下方爪子在照片边缘有裁切，仅在裁切边缘反射补入至多 18 像素的相邻毛纹；截短前臂、旋转为朝下的按键姿态，并在连接处淡化。左爪稍作曝光匹配，不重新生成爪子形象。

素材复现：`python scripts/extract-photo-paws.py`。来源、轮廓和局部补边记录在 `docs/paw-source-regions.json`。猫脸、毛边、键盘和无标志鼠标继续沿用上一版本。

## 1.0.8 爪子顶部过渡

两只照片爪子的根部改为圆弧型 alpha 轮廓，并做平滑渐隐，去除直线横切口和尖角。PNG 尺寸、脚尖和下半部像素保持不变，落点与动作锚点不变。

构建目录按版本隔离为 `release/build-版本/`，避免覆盖正在运行的旧版程序；`npm run dist` 完成后自动把 ZIP 复制到 `release/` 根目录。

## 1.0.9 初始落点

以猫面对用户为方向：画面左侧是猫的右爪，初始在 R；画面右侧是猫的左爪，初始在数字小键盘 +。按键或鼠标释放后回到对应初始落点。静止摆放不会高亮键位或增加统计。

## 1.0.10 动作节奏

猫爪随键位远近轻微倾斜，松开后回到 R／主键盘 +／=（初始落点已按最新要求更正）。待机时两爪错开节奏轻轻起伏，猫主体缓缓上下移动，整张照片保持原样，不对五官做形变。互动和休息话框位于猫左脸的右侧（画面右侧），分上下摆放，尾巴指向猫。

近 1.8 秒内的实际按下次数决定动作速度：打字越快，猫的起伏越快，爪子移动和转动也更利落。速度平滑过渡，上限为待机的 5 倍，停下后缓缓恢复；长按重复事件不加速。鼠标移动和滚轮不参与动作节奏。动画使用浏览器合成，不使用逐帧 JavaScript，恢复待机后停止节奏更新定时器；尊重系统减少动态效果设置。

## 键帽飘字

固定开启，没有开关。只在键盘附近显示文字，不抖屏、不遮挡、不加声音，猫叫完全沿用上面的原有逻辑；系统开启“减少动态效果”时不显示。

- 普通键：从键帽上冒出随机拟声词、猫词和薯词（啪、哒、咕噜、喵呜、踩踩、好薯、+1……），三种飘动方式随机出现。不显示真实按下的字母或数字，旁人看不出你打了什么。
- 功能键有专属台词：回车“发射！”、退格“后悔药”、Esc“溜了溜了”、空格“懵薯！”、F5“刷新！”、PrtSc“咔嚓！”、方向键“左左／右右”等。
- 常用快捷键有回应：Ctrl+C“复制！”、Ctrl+V“贴贴”、Ctrl+Z“时光倒流”、Ctrl+S“存好啦，薯饼安心~”、Alt+Tab“溜号~”、Win+D“回桌面看懵薯！”等。
- 打出一些拼音或英文词（输入法里打拼音也算）会冒出小气泡回应，例如 `moyu`“摸鱼被懵薯发现了”、`xiaban`“下班！冲鸭！”、`heshui`“二狗喝水好习惯”、`chifan`“二狗干饭！”、`mengshu`“在呢在呢！”。只在内存中匹配最近 16 个字母数字，不保存、不上报。
- 键帽飘字共 365 条不重复文案；点猫时冒几颗小爱心。打出 `ergou`、`shubing`、`subing` 也会被懵薯认出来。
- 按下的键不再叠加黄色强调色块，只由猫爪落点和飘字表现按键；键盘图片单独合成，打字时键帽上的印字不再闪烁。

## 话框文案

摸猫台词 520 条、休息提醒 1314 条，采用猫咪搭子口吻、网络用语、职场和游戏梗，每条配有颜文字。词汇风格参考[年度流行语盘点](https://paper.people.com.cn/fcyym/pc/content/202512/26/content_30133212.html)和[“爱你老己”报道](https://www.chinanews.com/sh/2025/12-28/10541834.shtml)，实际台词结合应用场景重新编写。
