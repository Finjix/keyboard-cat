懵薯 1.0.10 · Windows x64 便携版

完整解压到固定文件夹后，双击 懵薯.exe 即可运行，无需安装。
请保留同目录的 resources、locales 等配套文件。
右侧面板右上角的齿轮菜单提供开机自启与退出。
开机自启使用当前解压路径，移动文件夹后请重新打开程序。
猫主体使用原照片像素，轮廓经手工描线修整，头顶与脸颊保留原照片毛尖细节。
鼠标掌托无标志；猫五官保留原图，轮廓补有细毛效果。
两只猫爪使用新照片分别抠图，保留真实毛纹。
猫面对屏幕：右爪初始放 R，左爪初始放数字小键盘 +；释放输入后回到初始落点。

猫爪随键位轻轻转动；待机时猫与爪子有细微起伏。
打字越快动作越快，停下后逐渐恢复待机速度；长按重复、鼠标移动和滚轮不加速。
更新时先通过齿轮退出旧版，再打开新目录中的程序。
